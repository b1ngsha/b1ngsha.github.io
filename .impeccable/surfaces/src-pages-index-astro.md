# 首页（Experience）

Mode: Experience. 访客：招聘方和朋友。他们来认识冰沙这个人：名字、近况、年谱、文章。

## Direction contract

THESIS: 整个站点是一本正在被画的速写本，页面本身就是线稿。拒绝「个人博客 = 头像 + 文章列表 + 标签云」的默认排法；用一只会看人的眼睛当首屏。

OWN-WORLD: 近黑钢笔线（暗色里是白线）画在冷灰纸上，页面里只有一种颜色：红（裂纹、彼岸花、红笔划线、计数的斜线、太阳）。巨大的 200 字重宋体做标题，意大利体 Bodoni 做数字和英文，手写楷体做批注。线条先出草稿（浅灰构图线），再落墨；画完后轻微“沸腾”。

STORY: 访客看到一只眼睛被一笔笔画出来，瞳孔跟着鼠标，意识到这是一个人在认真做东西；往下依次读到近况（蛋挞和那句“这片天空太小了”）、年谱（荆棘线随滚动生长，尽头开出红色彼岸花）、文章（正字计数）；最后在尾声找到 GitHub、X、Telegram 和邮箱。

FIRST VIEWPORT: 眼睛占右上约 76vh，名字「冰沙」以 23vw 的 200 字重压在左下，右下一小段介绍；眼睛先画草稿线，约 7 秒画完，瞳孔此后跟随鼠标，每几秒眨一次。没有导航以外的按钮。

FORM: 来自 design-previews/lynn-round-3/f-ishida（用户选定），这是用户亲自选定的方向，不是抽签结果；seed key 与此无关。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
